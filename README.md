# 知页 · 知识分享站

一个无需构建步骤的静态网站，适合分享文章、视频和图解。它由 GitHub Pages 托管，内容可通过 Pages CMS 后台编辑。

## 网站内容

- `data/site.json`：网站名称、简介和默认作者名。
- `data/posts.json`：文章、视频与图解列表。
- `media/`：封面和图解图片。
- `.pages.yml`：Pages CMS 后台里的编辑表单和媒体上传设置。
- `admin/`：后台入口与使用说明。

## 管理与更新

1. 打开网站的「内容管理」入口，登录 [Pages CMS](https://app.pagescms.org) 并选择这个 GitHub 仓库。
2. 首次使用时，按提示将 Pages CMS 的 GitHub App 安装到此仓库。授权后，后台会直接读写网站内容与图片。
3. 在「分享内容」中新增或编辑文章、视频、图解，然后保存。
4. 保存会提交到 GitHub。GitHub Pages 随后发布新内容，通常需要等构建和缓存刷新。

GitHub Pages 只托管静态页面。Pages CMS 提供可视化编辑界面，内容和媒体文件仍保存在这个仓库中；它不需要也不使用个人访问令牌。首次授权 Pages CMS 前，可以先查看 GitHub 显示的仓库访问范围。

## 内容填写提示

- 文章正文使用富文本编辑器，可以写标题、段落、列表、链接并插入图片。
- 视频内容在「视频或图解地址」填哔哩哔哩 / YouTube 页面链接或 MP4 链接；推荐使用视频平台链接，不必把大视频文件提交到 Git 仓库。
- 图解可以通过「视频或图解地址」选图，或在正文编辑器里上传图片。
- `id` 是内容唯一编号，使用小写英文、数字或短横线，例如 `my-first-note`。
- 保存内容后即会进入公开站点；此仓库和其中的文章、图片都面向公众，不要在里面保存隐私或尚未公开的草稿。视频条目的「精选」也可以在后台设置。

## 本地预览

在此目录启动任意静态文件服务器，然后在浏览器打开本地地址。网站没有构建步骤或依赖包。
