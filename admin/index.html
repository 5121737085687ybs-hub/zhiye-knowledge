用 Pages CMS 管理文章、封面图、图解和视频链接。保存后会写入你的 GitHub 仓库，网站随后自动更新。

  1. 登录 Pages CMS
    使用持有此网站仓库的 GitHub 账号登录。
  2. 连接知页仓库
    首次使用时选择知页仓库并授权 CMS 访问。
  3. 编辑并保存
    在「分享内容」里新增或修改文章、视频和图解。
打开 Pages CMS ↗

后台通过 GitHub 账号验证，不需要在这个网站输入个人访问令牌。图片会保存到仓库；视频建议粘贴哔哩哔哩或 YouTube 链接。
